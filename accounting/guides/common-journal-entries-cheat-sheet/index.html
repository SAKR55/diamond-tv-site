ورقة القيود اليومية الشائعة

قيود جاهزة للعمليات المتكررة مع المعيار المرتبط.

مبيعات ومشتريات

  • بيع آجل: مدين ذمم مدينة / دائن إيراد (+ ضريبة مستحقة).
  • شراء نقدي: مدين مخزون / دائن نقدية.
  • مرتجع مبيعات: مدين مردودات المبيعات / دائن ذمم مدينة.

مصروفات وتسويات

  • مصروف مستحق: مدين مصروف / دائن مصروفات مستحقة.
  • مصروف مدفوع مقدمًا: مدين مدفوعات مقدمة / دائن نقدية ثم يُحمَّل شهريًا.
  • إهلاك: مدين مصروف إهلاك / دائن مجمع إهلاك.

ذمم وموظفون

  • مخصص خسائر ائتمانية: مدين مصروف / دائن مخصص.
  • رواتب مستحقة: مدين مصروف رواتب / دائن رواتب مستحقة.
  • مكافأة نهاية الخدمة: مدين مصروف منافع / دائن التزام منافع.

ضريبة وأخرى

  • ضريبة قيمة مضافة على المبيعات: دائن ضريبة مستحقة.
  • ضريبة المدخلات: مدين ضريبة قابلة للخصم.
  • فروق صرف: مدين/دائن ربح أو خسارة فروق عملة.
