أساسيات الواجهة البرمجية (API)

واجهة Claude البرمجية تتيح لك دمج Claude في تطبيقاتك. الطلب الأساسي: اسم النموذج، حد أقصى للمخرجات، قائمة رسائل (user/assistant)، ورسالة نظام (system) اختيارية تحدد الدور والقواعد.

الاستخدام يُحسب بالرموز (tokens) للمدخلات والمخرجات. اختصر السياق، وخزّن الأجزاء الثابتة الطويلة بميزة التخزين المؤقت للبرومت (prompt caching) إن توفرت لتقليل الكلفة والزمن. وللمهام غير العاجلة بالجملة توجد معالجة دفعية.

استخدام الأدوات (tool use): تصف لـClaude دوال يستطيع طلب استدعائها (مثل البحث في قاعدة بياناتك)، ويعيد لك طلب الاستدعاء بمعاملاته، فتنفذه أنت وتعيد النتيجة. هذا أساس الوكلاء.

أمان: لا تضع مفتاح API في كود المتصفح. استخدم خادمًا وسيطًا ومتغيرات بيئة، وحدد حدود الإنفاق، وراقب الاستخدام.

ملاحظة: ميزات Claude وأسماء النماذج والحدود تتغير. راجع موقع Anthropic ووثائقه الرسمية لما هو متاح في خطتك.

مثال: شكل طلب مبسّط (توضيحي)

{
  "model": "<اسم النموذج من الوثائق>",
  "max_tokens": 500,
  "system": "أنت مساعد خدمة عملاء لمتجر عربي. أجب بإيجاز وبأدب.",
  "messages": [{"role": "user", "content": "أين طلبي رقم 1042؟"}]
}

الهيكل نفسه يتكرر: نموذج وحد للمخرجات ونظام ورسائل. راجع الوثائق للأسماء الحالية.

راجع وثائق Anthropic الرسمية لتجربة أول طلب بنفسك.
