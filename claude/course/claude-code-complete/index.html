Claude Code الكامل: من الطرفية إلى الويب والجوال

Claude Code وكيل برمجة يعمل من الطرفية، وأيضًا من الويب وسطح المكتب والجوال. يقرأ ملفات مشروعك، يشغّل الأوامر، يعدّل الشيفرة، ويجري الاختبارات، ويمكنه فتح طلبات الدمج على GitHub بإذنك.

ملف CLAUDE.md في جذر المشروع هو دليل الفريق لـ Claude: أوامر البناء، أسلوب الكتابة، ما لا يُلمس. كل ما تكتبه هناك يُقرأ في كل جلسة. الأذونات تتحكم بما يُنفَّذ دون سؤال، والخطافات (Hooks) تشغّل أوامر تلقائيًا عند أحداث معينة كالتنسيق بعد كل تعديل.

الوكلاء الفرعيون يقسّمون المهمة الكبيرة (بحث متوازٍ، مراجعة) كلٌّ بسياقه الخاص، وخوادم MCP تربطه بأدوات خارجية كقاعدة بياناتك أو متتبع المهام.

التثبيت والبدء

Claude Code يُثبَّت ويعمل من الطرفية داخل مجلد مشروعك، وتتوفر نسخ على الويب وسطح المكتب والجوال. اتبع صفحة الوثائق الرسمية للتثبيت لأن الأوامر والمتطلبات تتغير.

  • ادخل مجلد المشروع قبل التشغيل ليرى Claude الملفات الصحيحة.
  • ابدأ بسؤال قراءة فقط: «اشرح بنية المشروع».
  • استخدم Git: افتح فرعًا للتجربة ليسهل التراجع.

CLAUDE.md والأذونات والخطافات

  • CLAUDE.md: أوامر البناء والاختبار، قواعد الكتابة، ما لا يجوز تعديله، تسمية الفروع. اكتبه مختصرًا واضحًا ولا تضع فيه أسرارًا.
  • الأذونات: تتحكم بما ينفذه Claude تلقائيًا وما يطلب إذنك له. ابدأ بالصارم ثم خفّف لما يتكرر.
  • الخطافات (Hooks): أوامر تُشغَّل تلقائيًا عند أحداث، مثل تشغيل المنسّق بعد كل تعديل أو منع كتابة ملفات حساسة.
  • أوامر مخصصة: احفظ برومت متكررًا كأمر تستدعيه باسمه.

الوكلاء الفرعيون وMCP والأتمتة

  • وكلاء فرعيون: مهمة كبيرة تُوزَّع على وكلاء بسياق مستقل (بحث في أجزاء الشيفرة، مراجعة أمنية) ثم يجمع الرئيسي النتائج.
  • MCP: ربط أدوات خارجية: قاعدة بيانات، متتبع مهام، مستودع، متصفح.
  • الجدولة: مهام دورية (فحص صباحي، تقرير أسبوعي) تُنفَّذ دون إشرافك لحظة بلحظة؛ اجعل صلاحياتها ضيقة.
  • قاعدة الأمان: لا تمنح صلاحيات حذف أو نشر دون مراجعة بشرية.

مشروعك الأول: خطوات عملية

  • اطلب خطة بدون تنفيذ.
  • نفّذ خطوة صغيرة وشغّل الاختبارات.
  • راجع الفروقات (diff) بنفسك.
  • لا تدمج ما لا تفهمه: اطلب منه الشرح.
