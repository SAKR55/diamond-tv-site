Claude Code بعمق: CLAUDE.md والأوامر والوكلاء الفرعيون

CLAUDE.md ملف في جذر مشروعك يقرؤه Claude Code تلقائيًا: وصف المشروع، أوامر البناء والاختبار، أسلوب الكتابة، المجلدات الحساسة. اجعله قصيرًا ومحدثًا.

أوامر الشرطة المائلة (Slash commands) تختصر طلبات متكررة، ويمكنك إنشاء أوامرك. وضع الخطة (Plan mode) يجعل الوكيل يخطط ويعرض خطته قبل التنفيذ. وإعدادات الصلاحيات تحدد ما يستطيع تشغيله دون سؤال.

الـHooks أوامر تُنفَّذ تلقائيًا عند أحداث معينة (مثل تشغيل المنسّق بعد كل تعديل). والوكلاء الفرعيون (Subagents) مساعدون متخصصون بسياق مستقل لمهام مثل البحث في الكود أو مراجعته.

عادات تضمن جودة العمل: خطة قبل التنفيذ، خطوات صغيرة، تشغيل الاختبارات، مراجعة الفروقات (diff)، والالتزام بنقاط حفظ صغيرة في Git. لا تمنح صلاحيات حذف أو دفع بلا مراجعة.

ملاحظة: ميزات Claude وأسماء النماذج والحدود تتغير. راجع موقع Anthropic ووثائقه الرسمية لما هو متاح في خطتك.

مثال: CLAUDE.md مختصر

# المشروع: متجر ثابت بالعربية RTL
- التشغيل: python3 -m http.server
- الاختبار: node tests/run.js
- الأسلوب: HTML نظيف، بدون مكتبات جديدة
- ممنوع: تعديل مجلد /legacy أو حذف ملفات بلا موافقة
- قبل أي دمج: شغّل الاختبارات وأخبرني بالنتيجة.

ملف قصير يعطي الوكيل القواعد ويقلل التصحيحات المتكررة.
