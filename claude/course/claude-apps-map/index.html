خريطة كل تطبيقات Claude ومنتجاته: أين أستخدم ماذا؟

Claude ليس تطبيقًا واحدًا بل عائلة منتجات تشترك في النماذج نفسها وتختلف في مكان العمل: التطبيق الأساسي للمحادثة والعمل المكتبي، وClaude Code للبرمجة، وClaude في Chrome للمواقع، وإضافات أوفيس وWorkspace لملفاتك، وClaude Tag داخل Slack، وواجهة API لبناء منتجاتك.

اختيار المكان الصحيح يوفر وقتًا أكثر من تحسين البرومت: مهمة جدول بيانات أنسب داخل Excel، ومهمة تعديل مستودع برمجي أنسب في Claude Code، وسؤال سريع أنسب للتطبيق.

هذه الخريطة وصف عام وقت كتابة الدرس؛ المنتجات والمزايا تتطور بسرعة، فراجع صفحات Anthropic الرسمية قبل الاعتماد على ميزة بعينها.

جدول القرار

عملي: «أريد تلخيص 30 ملف PDF» → التطبيق الأساسي مع Projects.
عملي: «أصلح خطأ في مستودعي» → Claude Code.
عملي: «احجز/قارن على موقع يحتاج تسجيل دخولي» → Claude في Chrome.
عملي: «حلّل جدولًا وأنشئ معادلات» → Claude في Excel.
عملي: «لخّص نقاش القناة» → Claude Tag في Slack.
عملي: «أبني بوت لمتجري» → API.

اسأل دائمًا: أين الملف أو البيانات الآن؟ اذهب بـ Claude إليها بدل نقلها.

ارسم خريطة شخصية: عمودان (مهمة ← منتج) لعشر مهام متكررة.

طبّق بنفسك

اكتب ثلاث مهام من أسبوعك الماضي واختر لكل واحدة المنتج الأنسب من الجدول.

تُحفظ ملاحظاتك على هذا الجهاز فقط.

متى أختار كل منتج؟ (تفصيل)

  • التطبيق الأساسي: كتابة، تحليل مستندات، بحث، أفكار، مشاريع ذات سياق ثابت، وأي مهمة لا تحتاج الوصول لملفاتك مباشرة.
  • Claude Code: كل ما فيه مشروع برمجي: قراءة الشيفرة، إصلاح الأخطاء، إضافة ميزات، اختبارات، أتمتة مهام الطرفية.
  • Claude في Chrome: مهام على مواقع تتطلب تسجيل دخولك أو التنقل بين صفحات: مقارنة، تعبئة نماذج، جمع معلومات.
  • الإضافات داخل أوفيس وWorkspace: حين يكون الملف نفسه هو العمل (جدول، عرض، مستند، بريد).
  • Claude Tag في Slack: سياق جماعي: تلخيص قنوات، متابعة قرارات، صياغة ردود لفريق.
  • API وConsole: حين تريد Claude داخل منتجك أنت: بوت متجر، أداة داخلية، معالجة آلاف المستندات.

ثلاثة أنماط استخدام شائعة

  • صاحب متجر: التطبيق الأساسي (Projects لهوية المتجر) + Excel للمخزون والأسعار + API لاحقًا لبوت خدمة العملاء.
  • مسوّق/كاتب: التطبيق الأساسي + Word وPowerPoint + موصل التقويم والبريد.
  • مطوّر: Claude Code + موصل GitHub + التطبيق الأساسي للأفكار والتوثيق.

ابدأ بمنتجين فقط ثم أضف حسب الحاجة الفعلية، لا حسب الفضول.

أخطاء شائعة

  • نقل ملف ضخم بالنسخ واللصق بينما توجد أداة تعمل داخله مباشرة.
  • الاعتماد على ميزة قرأت عنها دون التأكد أنها متاحة لخطتك وبلدك.
  • تفعيل كل الموصلات دفعة واحدة: كل موصل يوسّع ما يستطيع Claude رؤيته، فاربط ما تحتاجه فقط.
