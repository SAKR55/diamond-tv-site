5) الخطة أولًا: «اقترح خطة ولا تنفذ». 6) التدرج: «اكتب مسودة، ثم انقدها، ثم حسّنها». 7) التبسيط: «اشرحها لطالب إعدادي». 8) الاستخراج: «استخرج التواريخ والمبالغ في جدول».

9) خصم الحجة: «أعطني أقوى اعتراض على فكرتي». 10) القالب: «املأ هذا القالب بالبيانات». 11) الاختصار: «اختصر إلى النصف مع الحفاظ على الأرقام». 12) التنسيق: «حوّلها إلى JSON بالحقول التالية».
