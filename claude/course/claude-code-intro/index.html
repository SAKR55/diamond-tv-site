مدخل إلى Claude Code

Claude Code أداة من Anthropic للبرمجة بمساعدة وكيل ذكي يعمل داخل مشروعك، فيقرأ الملفات وينفذ أوامر ويعدّل الكود بموافقتك. وتتوفر بصيغ مثل الطرفية وبعض بيئات التطوير. راجع وثائق Anthropic لمعرفة المتاح حاليًا وطريقة التثبيت.

أهم عادة: لا تبدأ بطلب كبير. قدّم الهدف، واطلب خطة أولًا، ثم نفّذ جزءًا صغيرًا وجرّبه. ويمكنك كتابة ملف تعليمات للمشروع (يسمى CLAUDE.md) يضم أوامر التشغيل والاختبار وقواعد الكود ليقرأه الوكيل في بداية العمل. راجع دائمًا التغييرات قبل اعتمادها.

مثال محلول: بداية مهمة برمجية

الهدف: إضافة صفحة «اتصل بنا» لموقع ثابت.
القيود: لا تغيّر ملف الأنماط الرئيسي. استخدم نفس الخطوط.
المطلوب الآن: اقترح خطة بملفات سيتم تعديلها، ولا تعدّل شيئًا قبل موافقتي. بعد الموافقة نفّذ ثم اشرح ما تغيّر.

الخطة أولًا تتيح لك رفض اتجاه خاطئ قبل أن يعدّل الوكيل ملفات.

اختر نوع «برمجة» في الأداة وافتح تبويب «تعليمات المشروع / CLAUDE.md».

طبّق بنفسك

اكتب ملف CLAUDE.md من ثمانية أسطر لمشروع صغير: وصفه، أوامر التشغيل، قواعد الأسلوب، وما يُمنع تعديله.

ما هو وما يناسبه

Claude Code أداة لتنفيذ مهام البرمجة من سطر الأوامر والبيئات المدعومة: قراءة المشروع وتعديل الملفات وتشغيل الاختبارات. يناسب من يريد مساعدًا يعمل داخل مشروعه لا محادثة منفصلة.

أول استخدام آمن

  • ابدأ في فرع جديد (Git).
  • اطلب من الأداة شرح بنية المشروع قبل التعديل.
  • راجع كل تعديل قبل اعتماده.
  • لا تمنحها صلاحيات واسعة دون حاجة.
