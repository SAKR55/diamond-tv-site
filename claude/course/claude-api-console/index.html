واجهة API ولوحة Console: ابنِ منتجك

واجهة Claude البرمجية تتيح دمج النماذج في تطبيقك أو بوت متجرك. تدخل Console لإنشاء مفتاح وضبط حدود الإنفاق ومراقبة الاستخدام، ثم ترسل رسائل إلى نقطة Messages محددًا النموذج وأقصى طول للرد.

أهم المفاهيم: رسالة النظام (تعليمات دائمة)، استدعاء الأدوات (Tool use) ليستدعي النموذج دوالّك، الدفعات (Batch) لمهام ضخمة غير عاجلة بتكلفة أقل، والتخزين المؤقت للبرومت لتخفيض كلفة السياق المتكرر، والتدفق (Streaming) لعرض الرد تدريجيًا.

لا تضع المفتاح في شيفرة الواجهة الأمامية أبدًا؛ مكانه الخادم أو متغيرات البيئة. وراجع وثائق docs.claude.com لأسماء النماذج والحدود الحالية.

أول طلب (Python)

import anthropic
client = anthropic.Anthropic()
r = client.messages.create(
    model="claude-sonnet-5-5",
    max_tokens=500,
    system="أنت مساعد متجر يرد بإيجاز وبالعربية.",
    messages=[{"role":"user","content":"ما سياسة الإرجاع؟"}])
print(r.content[0].text)

المفتاح يُقرأ من متغير البيئة ANTHROPIC_API_KEY ولا يُكتب في الشيفرة.

صمّم رسالة نظام لبوت يجيب عن أسئلة الشحن فقط ويحوّل ما سواها لبشري.

طبّق بنفسك

أنشئ مفتاحًا تجريبيًا بحد إنفاق صغير ونفّذ الطلب أعلاه.

تُحفظ ملاحظاتك على هذا الجهاز فقط.

الأجزاء الأساسية

  • Console: إنشاء مفاتيح، حدود إنفاق، مراقبة الاستخدام، مساحات عمل للفرق.
  • Messages: الطلب الأساسي: النموذج، max_tokens، messages، وsystem.
  • Tool use: تعرّف للنموذج دوالًا (مثل «تحقق من حالة طلب»)، فيطلب استدعاءها وتعيد أنت النتيجة.
  • Batch: معالجة دفعية غير فورية بتكلفة أقل.
  • Prompt caching: تخزين الجزء الثابت من البرومت لتخفيض كلفة التكرار.
  • Streaming: عرض الرد تدريجيًا.

بوت متجر: بنية مقترحة

١) رسالة نظام: دور البوت، سياسات الشحن والإرجاع، حدود ما يجيب عنه، متى يحوّل لبشري.

٢) أداة «حالة الطلب» تستدعي نظامك.

٣) تسجيل المحادثات (دون بيانات حساسة) لتحسين الأجوبة.

٤) اختبار على 50 سؤالًا حقيقيًا قبل الإطلاق.

٥) حد إنفاق ومراقبة يومية.

أمان وتكلفة

  • المفتاح في الخادم فقط، ودوّره عند الشك بتسريبه.
  • حدّ إنفاق صغير في البداية.
  • قلّل max_tokens للمهام القصيرة.
  • لا تُرسل بيانات شخصية إلا عند الحاجة، وفق سياسة الخصوصية.

الوثائق الرسمية هي مرجع الأسماء والحدود الحالية.
