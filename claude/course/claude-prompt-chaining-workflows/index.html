سلاسل المهام (Prompt Chaining)

السلسلة: مخرجات خطوة تصبح مدخلات التالية: تحليل ← خطة ← مسودة ← مراجعة ← صياغة نهائية.

كل حلقة بتعليمات قصيرة ومعيار قبول، وتتحقق قبل الانتقال.

اطلب مخرجات منظمة (قوائم، JSON) لتسهل استخدامها في الحلقة التالية.

يمكن أتمتة السلاسل لاحقًا عبر الأدوات والـAPI عند ثبات الوصفة.

مثال: حملة

1) حلّل جمهورنا → 2) اقترح 3 رسائل → 3) اكتب إعلانًا لرسالة 2 → 4) انتقده → 5) النسخة النهائية.

كل مرحلة تُرفع جودتها بمراجعتك.

نفّذ سلسلة يدوية من 3 خطوات.
