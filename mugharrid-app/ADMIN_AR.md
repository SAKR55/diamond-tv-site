# التحكم بتطبيق مغرّد (لوحة التحكم)

## ما تستطيع فعله
- **المستخدمون**: عرض الكل، بحث، تعديل الاسم والجوال، إيقاف/فك إيقاف حساب، حذف بياناته، تصدير CSV، ومشاهدة المستوى والنقاط والسلسلة وآخر نشاط.
- **المحتوى**: إضافة جمل وتعابير ومواضيع ومهمات بسطر لكل عنصر، ودروس ونصوص قراءة ومحادثات بصيغة JSON (بقوالب جاهزة)، وإعلان أعلى الرئيسية.
- النشر يصل الجميع عند فتح التطبيق بلا تحديث من المتجر. المحتوى يُضاف إلى المدمج ولا يحذف منه.
- لا تستطيع الإدارة قراءة محادثات الأصدقاء (محمية بالقواعد).

## الإعداد (مرة واحدة)
1. Firebase ← Authentication: أنشئ حساباً (بريدك) من تبويب Users ← Add user، وانسخ **User UID**.
2. Firestore ← Start collection باسم `admins` ← Document ID = الـUID الذي نسخته ← أضف حقلاً أي قيمة (مثل `ok` = true).
3. Firestore ← Rules: الصق محتوى `firebase/firestore.rules` ثم Publish.
4. Project settings ← Your apps ← أضف تطبيق **Web** (</>) وانسخ firebaseConfig.
5. افتح `admin/panel.html` من استضافة (Firebase Hosting أو GitHub Pages أو Netlify Drop) — أو محلياً بـ `python3 -m http.server` داخل مجلد admin ثم http://localhost:8000/panel.html.
   Authentication ← Settings ← Authorized domains: أضف نطاق الاستضافة (localhost موجود).
6. الصق الإعدادات في أول شاشة، ثم ادخل ببريدك.

## ملاحظات
- لتعديل جديد كلياً في الأقسام: تصنيف القراءة/المحادثات يجب أن يطابق معرّفات الأقسام الموجودة.
- حذف حساب الدخول نهائياً يتم من Authentication في Firebase.
- الإشعارات والتوليد التلقائي بالذكاء الاصطناعي تحتاج خادماً وليست ضمن اللوحة.

## لوحة التحكم v2: كل ما تستطيع فعله
- **أقسام المحتوى** (جمل، تعابير، مواضيع، مهمات، كلمات الأطفال، قراءة، دروس، محادثات): نموذج إضافة بسيط لكل قسم، ولصق عدة أسطر دفعة واحدة، وتعديل وحذف، ثم زر «نشر».
- **توليد وجلب** من الإنترنت:
  - اقتراحات اليوم من ويكيبيديا (الأكثر قراءة) تتحول إلى نص قراءة بمفردات مترجمة.
  - جلب موضوع بالاسم، أو لصق نص أو رابط مقال.
  - كلمات ⟵ جمل بأمثلة حقيقية مترجمة (dictionaryapi.dev وMyMemory).
  - اختياري: توليد بالذكاء الاصطناعي بمفتاح Anthropic الخاص بك (يُحفظ في متصفحك فقط).
- **التحكم بالتطبيق والصوت**: صوت الجوال المفضل وسرعته وحدته، وصوت من الإنترنت عبر رابط، وإخفاء أي قسم من الرئيسية، ووضع الصيانة.
- **تحسينات في اللوحة**: التحقق من الأخطاء قبل النشر، ونسخ احتياطية تلقائية عند كل نشر مع استرجاع، ورسم التسجيلات، وتوزيع المستويات، والأعلى نقاطاً، ورسائل واتساب للمنقطعين.

### الصوت من الإنترنت
التطبيق يستدعي الرابط الذي تضعه ويعطيه الجملة مكان `{text}`، ويشغّل ملف mp3 الراجع. عند أي فشل يعود لصوت الجوال.
لا تضع مفتاح الخدمة (ElevenLabs أو Google أو Azure) في الرابط. اجعل بينك وبينها وسيطاً بسيطاً (مثل Cloudflare Worker) يحمل المفتاح.
بعد هذا التحديث نفّذ `flutter pub get` لأنه أضاف حزمة `audioplayers`.

## 🚀 التحديثات والإشعارات (تبويب «تحديثات وإشعارات»)
- **إرسال تحديث:** ابنِ النسخة الجديدة بعد رفع الرقم في `pubspec.yaml` (مثل `version: 1.1.0+5`)، وارفعها على موقعك أو Google Play، ثم في اللوحة ضع رقم build (5) والرابط وما الجديد ← «نشر التحديث». كل مستخدم نسخته أقدم يصله إشعار ونافذة «حدّث الآن». خيار «إلزامي» يمنع الاستخدام حتى التحديث.
- **إشعار للجميع:** عنوان ونص ورابط اختياري ← «إرسال». يظهر لكل مستخدم مرة واحدة عند فتح التطبيق (إشعار على الجوال ونافذة).
- **حد مهم:** هذا ليس دفعاً فورياً والتطبيق مغلق. الدفع الفوري يحتاج Firebase Cloud Messaging وخادماً يرسل، ويمكن إضافته لاحقاً.
- بعد هذا التعديل نفّذ `flutter pub get` (أُضيفت حزمة package_info_plus).
