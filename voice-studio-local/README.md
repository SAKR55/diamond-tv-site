# DIAMOND Voice Studio (محلي)

تطبيق يعمل على جهازك لاستنساخ الصوت ونطق النص بالعربية بصوت المرجع، باستخدام Chatterbox Multilingual (ترخيص MIT، يدعم العربية). لا يُرسل صوتك أو نصك لأي خادم بعد تنزيل النموذج أول مرة.

## المتطلبات
- Python 3.11 (المختبَر عند مطوري النموذج).
- مساحة حرة عدة جيجابايت للنموذج.
- يُفضَّل كرت NVIDIA (CUDA). بدونه يعمل على المعالج ببطء شديد. أجهزة Apple تعمل عبر MPS.

## التثبيت
- ويندوز: شغّل `install_windows.bat` ثم `run_windows.bat`.
- ماك/لينكس: `sh install_mac_linux.sh` ثم `sh run_mac_linux.sh`.
- كرت NVIDIA: قبل التثبيت فعّل البيئة وثبّت PyTorch بنسخة CUDA من موقع PyTorch الرسمي، ثم نفّذ `pip install -r requirements.txt`.

تفتح الواجهة في المتصفح على `127.0.0.1`.

## الاستخدام
1. أكّد أن الصوت المرجعي صوتك أو لديك إذن صاحبه.
2. «نص ← كلام»: اكتب النص، ارفع مرجعًا (10–20 ثانية نظيفة)، اختر العربية، ثم ولّد.
3. «تحويل تسجيل»: يحوّل تسجيلك إلى نبرة المرجع مع بقاء كلامك.
4. اضبط «التمسّك بالمرجع» و«الانفعال» و«التنويع» حتى تحصل على أقرب نتيجة.

## ملاحظات
- لم أتمكن من تشغيل هذا التطبيق أثناء كتابته (بيئتي بلا شبكة ولا كرت شاشة)، فقد تحتاج بعض الأسماء لتعديل بسيط حسب إصدار المكتبة. أرسل لي نص أي خطأ يظهر.
- تحمل الملفات الناتجة علامة مائية غير مسموعة من النموذج.
- لا تستخدم النتائج للانتحال أو الخداع.

## استقبال الإضافة (المنفذ 7861)
نقاط: GET /ping، POST /ref (WAV مرجعي)، POST /tts (JSON: text, lang, tries) → WAV، POST /vc (WAV) → WAV. تتطلب الترويسة X-DH-Ext: 1.
