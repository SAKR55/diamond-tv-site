استخدم ChatGPT في البرمجة وتصحيح الأخطاء

اكتب مواصفات صغيرة واختبر الحالات الحدّية قبل دمج الكود.

كيف تبدأ؟

حدّد اللغة والمدخل والمخرج المتوقع، ثم أعط مثالًا ينجح وآخر يكشف العطل. استخدم بيانات تجريبية، وشغّل الكود في نسخة عمل معزولة. إذا أعاد ChatGPT كتابة الدالة، افحص أثر التغيير على المستدعين.

جرّب بمثال

دالة JavaScript تحسب متوسط مدة الدروس. [10,20] تعطي 15. القائمة الفارغة تعيد null. الصفر مدة صالحة.

طلب جاهز للتجربة

اكتب الدالة واشرح سبب معالجة القائمة الفارغة أولًا. أرفق اختبارات للحالات [] و[0] و[10,20] دون تغيير سياسة البيانات الناقصة.
عدّل هذا المثال في المختبر
اعرض الحل وطريقة التحقق

النتائج الصحيحة هي null ثم صفر ثم 15. استخدام شرط يستبعد كل قيمة غير صادقة قد يحذف الصفر؛ اختبر [0,10] ويجب أن تحصل على 5.

تحدٍّ مستقل

أدخل نصًا بدل رقم وحدّد هل ترفض المدخل أم تحوّله. اكتب السلوك المطلوب صراحة قبل تعديل الدالة.
